# virtualRDBViwer

Vite + React で構築された Web アプリケーションです。

## 前提条件

- Node.js 18 以上（開発環境では v25 を確認済み）

## セットアップ

```bash
npm install
```

## 開発サーバー

```bash
npm run dev
```

http://localhost:5173 で起動します。`src/` 以下のファイルを編集するとホットリロードされます。

## ビルド

```bash
npm run build
```

`dist/` に本番用ビルド結果が出力されます。

## 本番プレビュー

```bash
npm run preview
```

## lint

```bash
npm run lint
```
